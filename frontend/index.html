General

Auto-selects the best model per message. Short chat → fast local model. Code/math → reasoning model. Image + file → vision extraction pipeline.

Routing rules (priority order):
• Image/file attached + non-vision model → Gemini Flash extracts, original model reasons
• Code/math keywords or long query → DeepSeek R1 (reasoning)
• Short (<15 words) conversational → Llama 3.2 3B (fastest)
• Manual model pick (last 5 min) → always honored
• Default → your selected model
